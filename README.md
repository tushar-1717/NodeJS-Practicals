# Node.js Practicals

This repository contains the **Node.js Practical Programs** performed as part of the MCA NEP Curriculum at **G.H. Raisoni College of Engineering and Management**.

The practicals cover Node.js fundamentals, modules, file handling, REST APIs, Express.js, MongoDB, Mongoose, authentication, sessions, cookies, and web application development.

## ⚙️ Requirements

Before running the practical programs, make sure the following are installed:

* Node.js
* NPM
* MongoDB (for database-related practicals)
* Visual Studio Code or another code editor

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/NodeJS-Practicals.git
```

### 2. Open the Repository

```bash
cd NodeJS-Practicals
```

### 3. Open a Practical Folder

For example:

```bash
cd Practical-01
```

### 4. Run the Node.js Program

```bash
node filename.js
```

For example:

```bash
node app.js
```

### 5. Install Required Packages

For practicals using Express, Mongoose, or other external packages:

```bash
npm install
```
